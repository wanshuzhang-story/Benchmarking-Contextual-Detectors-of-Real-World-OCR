# Data rights and source provenance

- `LICENSE` (MIT) covers repository code. Do not infer that it licenses third-party scans or viewer images.
- The UK and US OCR-text sources have their own licenses and attribution expectations; see the cited British Library Heritage Made Digital and PleIAs US-PD dataset pages and the manuscript references. The age of the original newsprint does not alone establish the license of digital page images.
- This repository contains OCR sentences, labels, scores and locators already supplied for the research but **does not contain BNA newspaper scan images**.
- No API credentials, author identifiers in file-creator metadata, or model-cache secrets have been shipped.
- Before public anonymous submission, verify all re-use rights and institutional research-data release requirements.
