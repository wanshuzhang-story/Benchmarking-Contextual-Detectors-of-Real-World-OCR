# Known limitations, missing evidence and release conditions

1. **Population versus labeled truth:** complete UK four-query population `n=3,083`, but original row-level context labels exist only for 2,202 satire cases. Historical non-satire totals (0 hoax, 0 misinformation, 5 parody suspected OCR substitutions) were published as *aggregates* and must not be used to invent specific labeled cases.
2. **Inferred versus read words:** 186 original context-inferred satire words are preserved, plus later inferred non-satire words; none was independently page-rechecked during this repair. The separate third-person image check contains 46 recorded words in a selected 60-case sample, not 3,083 image labels.
3. **Different human context versions:** 72 later suspected substitutions across 3,083 cases are not original labels. The two supplied later review sources disagree on at least some word candidates, including `information` versus `this information`. The original satire context version differs from the newer version on 339/2,202 four-class comparisons. Avoid choosing one as unquestionable gold without adjudication.
4. **External audit mixed quality:** 1,093 sampled; final 1,084 resolved and 49 reported substitutions. Only 80 rows in the actual supplied external CSV carry a `printed_word` string. Most old `genuine` decisions were recorded without one. A recheck note `not found in BNA` conflicts with five conclusive verdicts; review those images before treating them as page-confirmed.
5. **Verification-selection bias:** the 111-case blind recheck was selected partly by model scores (54 LLM, 30 encoder), not an independent random verification sample. Thus 0.970 Claude q-normalized AUC and other excellent post-recheck AUCs are descriptive of those *selected/rechecked paper labels*, not proof of unbiased population performance. Present both initial-label and final-label sensitivities.
6. **Different sampling designs:** 60 targeted UK satire image checks and 80 word transcriptions from the random audit cannot be pooled as a single random benchmark. A 100-case targeted US satire check and its 99/100 result were described in pre-existing notes but the underlying source file was not supplied; no dummy 100 rows have been generated.
7. **Historical corpus and API requests:** the original 50-million default conflicts with manuscript 30-million claim, and exact corpus snapshots/tokens are missing. The 11-cell exposure rho=0.79 and its p-value cannot be independently reproduced from these inputs. The original LLM script did not explicitly specify temperature=0; the new option is only for future requests.
8. **OCR mechanism classes:** substitutions of proper names, multiword strings, segmentation, and mixed newspaper columns must be separately flagged and defined before claiming all are simple one-token real-word OCR substitutions.
9. **Rights:** British Newspaper Archive image viewer content is not made CC0 by the public-domain age of newspaper text; no British Newspaper Archive scans are included. Source URLs can require access.
10. **Anonymous release:** cell-level authorship and identifying bibliographic self-citations still require a final institutional double-blind check before publishing. Metadata creator/last-modifier fields in copied `.xlsx` inputs have been anonymized. The PDF source TeX was not attached; `MANUSCRIPT_EXACT_CHANGES.md` refers to positions in the supplied 5-page PDF.
